## 1. Purpose & scope

Project 03 is the **production floor** of the initiative: it consumes the Project 00 reference layer and produces the school's actual classroom teaching artifacts for an Islamic primary school in Sylhet (Nursery, KG, Classes 1–5; +1 class/year). The sole user is the Principal.

This is where the **bulk of manual content production** happens. It does not invent policy, methodology, or analysis — those are settled upstream (Projects 00/01/02). It applies them, lesson by lesson.

## 2. What this Project produces

Two work-products, in this fixed order (D-PROJ03-001):

1. **Annotated skeleton** — the completed stability skeleton (Project 01, REF-05) with the **Islamic Curation Policy (REF-01)** applied: every lesson/পাঠ tagged **KEEP-AS-IS**, **NEEDS-REPLACEMENT**, or **FLEXIBLE**. An inventory exercise.
2. **Three-layer lesson plans** — one plan per lesson, on the canonical **REF-02** template, specialized by the relevant **Subject Spine Playbook (REF-03)**, with any replacement content embedded inline.

**The production cycle** spans three Projects:

> **P03 annotated skeleton** (flags NEEDS-REPLACEMENT lessons) → **P05 replacement content** (authors the flagged pieces) → **P03 lesson plans** (embed the content inline). Question banks (P04) follow.

So Project 03 both *opens* the cycle (skeleton) and *closes* it (plans), with Project 05 in the middle.
