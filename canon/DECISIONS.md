| CD-020 | 2026-08-09 | **Third manifest status added: `VENDORED-UNPROVEN`.** `PENDING` = not vendored · `VENDORED-UNPROVEN` = present but never executed · `REQUIRED` = proven · `DEFERRED` = deliberately absent. The old two-state scheme went silent at exactly the wrong moment — a PENDING row's warn vanished the instant the file appeared, so a vendored-but-never-run tool looked identical to a proven one.
