# C1 গণিত — অধ্যায় ১৪: যোগ

**অবস্থা:** নির্মাণাধীন (খসড়া — মানব-যাচাই বাকি)

## পরিসর

- **ছাপা:** ৯৭–১০০ (কর্তৃত্বপূর্ণ)
- **PDF (split-ফাইল):** ১৬–১৯ — এই আপলোড করা বিভাজিত ফাইলের নিজস্ব পৃষ্ঠাক্রম
- **PDF (পূর্ণ বই):** অজানা — মূল বইয়ের offset পৃথকভাবে নির্ণেয়

## উৎস-নোট

- উৎস ফাইলটি পূর্ণ বইয়ের একটি **বিভাজিত অংশ**; এই ফাইলের ভিতরে ছাপা = PDF + ৮১। পূর্ণ বইয়ের offset এখান থেকে নির্ণয় করা যায় না।
- ফাইলে **কোনো text layer নেই**; সব পাঠ ৪০০ dpi raster থেকে চোখে পড়া।
- প্রতিটি যোগের অঙ্ক আলাদা করে বড় করে পড়া হয়েছে; `৪` ও `৮` একই পাতায় পাশাপাশি মিলিয়ে যাচাই করা হয়েছে (ছাপা ৯৭ ক্রম ৩/৪, ছাপা ১০০ ক্রম ৫/৮)।
- **কোনো যোগফল হিসাব করা হয়নি**; যা ছাপা আছে কেবল তাই লেখা, ফাঁকা ঘর ফাঁকাই।
- উল্লম্ব যোগের সাজানো (দশক/একক কলাম, যোগচিহ্ন, রেখা) হুবহু রাখা হয়েছে; একটিকেও এক লাইনে মেলানো হয়নি।
- বইয়ে অধ্যায়ের ছাপা নম্বর নেই; লাল শিরোনাম "যোগ", চলতি-শিরোনামও "যোগ"।

## পাঠ্য

### ছাপা ৯৭

- চলতি-শিরোনাম (বাম-উপরে): যোগ
- অধ্যায়-শিরোনাম (লাল): **যোগ**
- প্রশ্ন-আইকনসহ বাক্স: ৩০টি খাতা ছিল । পরে আরও ২০টি খাতা কেনা হলো। একসাথে কয়টি খাতা হলো?
- স্থানীয় মানের ছক, দুই কলাম: | দশক | একক |
  - উপরের সারি: দশক ঘরে ৩টি দশের দণ্ড; একক ঘর ফাঁকা
  - নিচের সারি: দশক ঘরে ২টি দশের দণ্ড; একক ঘর ফাঁকা
- বালকের কথা-বেলুন: কীভাবে হিসাব করবে ব্যাখ্যা করো।
- বালকের কথা-বেলুন: আমরা ১০ এর দলের কথা ভাবতে পারি। আমরা ৩টি দশের দলের সাথে ২টি দশের দল যোগ করব।
- ছাপা লাইন: ৩০ + ২০ =  [ ]        [ ] টি খাতা
- কাজ-আইকনসহ লাইন: যোগ করি
  - (১) ৪০ + ১০   (২) ৬০ + ২০   (৩) ৪০ + ৫০
  - (৪) ১০ + ৮০   (৫) ৩০ + ৩০   (৬) ৬০ + ৪০
- **কাজ:** দশের দল হিসেবে ভেবে দুই সংখ্যার যোগ করা এবং ফাঁকা ঘরে যোগফল লেখা।
- **চিত্র:** বাঁ পাশে তিনটি খাতার বান্ডিল, নীল তির-চিহ্নের ভিতরে ডান পাশে আরও দুটি বান্ডিল; স্থানীয় মানের ছকে দশের দণ্ড; একজন বালক।

### ছাপা ৯৮

- চলতি-শিরোনাম (ডান-উপরে): প্রাথমিক গণিত
- প্রশ্ন-আইকনসহ বাক্স: ৪১ + ১৬ কীভাবে হিসাব করি?
- স্থানীয় মানের ছক, দুই কলাম: | দশক | একক |
  - উপরের সারি: ৪টি দশের দণ্ড; একক ঘরে ১টি একক ঘনক
  - নিচের সারি: ১টি দশের দণ্ড; একক ঘরে ৬টি একক ঘনক
- বালকের কথা-বেলুন: কীভাবে হিসাব করবে ব্যাখ্যা করো।
- বালকের কথা-বেলুন: একক ও দশক স্থানের অঙ্ক আলাদাভাবে যোগ করতে হবে।
- বালকের কথা-বেলুন: বাম পাশের মতো স্থানীয় মানের ছক ব্যবহার করে আমরা হিসাব করতে পারি।
- উল্লম্ব যোগ (ছাপা যেমন, শিরোনাম-ঘরসহ):

```
     দশক | একক
       ৪      ১
  +    ১      ৬
  ------------------
       ৫      ৭
```

- ছাপা লাইন: ৪১ + ১৬ =  [ ]
- কাজ-আইকনসহ লাইন (লাল): যোগ করি
  - (১) ৩২ + ২০   (২) ৪০ + ১৫   (৩) ৫১ + ১৪
  - (৪) ৫৬ + ২৩   (৫) ২২ + ৪৪   (৬) ৩৪ + ৬২
- **কাজ:** স্থানীয় মানের ছকে একক ও দশক আলাদা করে যোগ করা।
- **চিত্র:** দশের দণ্ড ও একক ঘনকের ছক; তিনটি কথা-বেলুনসহ বালক।

### ছাপা ৯৯

- চলতি-শিরোনাম (বাম-উপরে): যোগ
- প্রশ্ন-আইকনসহ বাক্স: নিচের যোগগুলো কীভাবে করতে হবে?
- **(১) ২৩ + ৫**
  - স্থানীয় মানের ছক: উপরের সারি — দশক ঘরে ২টি দশের দণ্ড, একক ঘরে ৩টি একক ঘনক; নিচের সারি — দশক ঘর ফাঁকা, একক ঘরে ৫টি একক ঘনক
  - বালকের কথা-বেলুন: একক ও দশক স্থানের অঙ্ক আলাদাভাবে যোগ করতে হবে।
  - বালকের কথা-বেলুন: লক্ষ করো, ৫ এর দশক স্থানে কিছু নেই।
  - উল্লম্ব যোগ:

```
     দশক | একক
       ২      ৩
  +           ৫
  ------------------
      [ ]    [ ]
```

  - ছাপা লাইন: ২৩ + ৫ =  [ ]
- **(২) ৪ + ৩২**
  - স্থানীয় মানের ছক: উপরের সারি — দশক ঘর ফাঁকা, একক ঘরে ৪টি একক ঘনক; নিচের সারি — দশক ঘরে ৩টি দশের দণ্ড, একক ঘরে ২টি একক ঘনক
  - উল্লম্ব যোগ:

```
     দশক | একক
              ৪
  +    ৩      ২
  ------------------
      [ ]    [ ]
```

  - ছাপা লাইন: ৪ + ৩২ =  [ ]
- **কাজ:** এক-অঙ্কের সংখ্যা দুই-অঙ্কের সংখ্যার সঙ্গে যোগ করা, দশক স্থান খালি থাকার বিষয়টি লক্ষ করা।
- **চিত্র:** দুটি স্থানীয় মানের ছক দণ্ড ও ঘনকসহ; দুই বালক কথা-বেলুনসহ।

### ছাপা ১০০

- চলতি-শিরোনাম (ডান-উপরে): প্রাথমিক গণিত
- কাজ-আইকনসহ লাইন (লাল): যোগ করি  *(পাতার প্রথম যোগ-ব্লক)*
  - (১) ৩১ + ৪   (২) ৪৩ + ৬   (৩) ৭০ + ২   (৪) ৬২ + ৫
  - (৫) ৪ + ৮১   (৬) ৯ + ৫০   (৭) ৩ + ৪৪   (৮) ৭ + ৯২
- কাজ-আইকনসহ লাইন (লাল): যোগ করি  *(দ্বিতীয় ব্লক — উল্লম্ব, ফলের সারি ফাঁকা)*

```
(১)    ২   ৪        (২)    ৩   ২        (৩)    ৬   ০
   +   ১   ৩           +   ৪   ১           +   ২   ৯
   ------------          ------------        ------------
      [ ] [ ]              [ ] [ ]              [ ] [ ]

(৪)    ৪   ০        (৫)        ৬        (৬)    ৫   ৫
   +   ৫   ০           +   ৪   ১           +       ৪
   ------------          ------------        ------------
      [ ] [ ]              [ ] [ ]              [ ] [ ]
```

- কাজ-আইকনসহ লাইন (লাল): যোগ করি  *(তৃতীয় ব্লক)*
  - (১) ৩০ + ৬০   (২) ৫৫ + ২২   (৩) ২৭ + ৪১   (৪) ২০ + ৫৩
  - (৫) ৫ + ৭১   (৬) ৯২ + ৬   (৭) ৫৩ + ৩৫   (৮) ৭১ + ১১
- কাজ-আইকনসহ শব্দ-সমস্যা ১ (ক্রমিক নম্বর ছাপা নেই): বিদ্যালয়ের একটি শ্রেণিতে ২৩ জন ছাত্র এবং ২৫ জন ছাত্রী আছে। ঐ শ্রেণিতে মোট কতজন ছাত্র-ছাত্রী আছে?
- কাজ-আইকনসহ শব্দ-সমস্যা ২ (ক্রমিক নম্বর ছাপা নেই): তিথির ২৭টি রঙিন কাগজ আছে। বাবা তাকে আরও ৪০টি রঙিন কাগজ দিলেন। তার কাছে এখন কয়টি রঙিন কাগজ হলো?
- **কাজ:** সারিবদ্ধ ও উল্লম্ব দুই ধরনের যোগ অনুশীলন এবং দুটি শব্দ-সমস্যার সমাধান।
- **চিত্র:** কোনো দৃশ্য-চিত্র নেই; কেবল কাজ-আইকন ও ছাপা অঙ্ক।

## চিত্র-বাহিত লেখা (raster-only)

সব গণনা দুইবার, আলাদা দুই passe; প্রতিটি **একক-চ্যানেল পাঠ** (সংখ্যাটি কেবল ছবিতে আছে, লেখায় নয়)।

### ছাপা ৯৭
- খাতার বান্ডিল: তির-চিহ্নের বাইরে (বাঁ পাশে) = **৩**, তির-চিহ্নের ভিতরে (ডান পাশে) = **২** (pass ১ ও ২ একই)।
- বান্ডিলের মোড়কে ছোট ছাপা লেখা আছে, কিন্তু ৪০০ dpi-তেও **পাঠযোগ্য নয়**; কী লেখা তা নির্ণয় করা যায়নি। দুই passe-এ একই রায়।
- স্থানীয় মানের ছক: উপরের সারিতে দশের দণ্ড = **৩**, নিচের সারিতে = **২**; দুই সারির একক ঘরই খালি (কোনো ঘনক নেই, শূন্যের কোনো চিহ্নও ছাপা নেই)।

### ছাপা ৯৮
- স্থানীয় মানের ছক: উপরের সারি — দশের দণ্ড = **৪**, একক ঘনক = **১**; নিচের সারি — দশের দণ্ড = **১**, একক ঘনক = **৬** (pass ১ ও ২ একই; ছবির এই গণনা ছাপা ৪১ ও ১৬-এর সঙ্গে মেলে)।

### ছাপা ৯৯
- (১)-এর ছক: উপরের সারি — দণ্ড = **২**, ঘনক = **৩**; নিচের সারি — দণ্ড = **০**, ঘনক = **৫** (ছাপা ২৩ ও ৫-এর সঙ্গে মেলে)।
- (২)-এর ছক: উপরের সারি — দণ্ড = **০**, ঘনক = **৪**; নিচের সারি — দণ্ড = **৩**, ঘনক = **২** (ছাপা ৪ ও ৩২-এর সঙ্গে মেলে)।
- প্রতিটি দশের দণ্ডে ছোট ঘর = **১০** (নমুনা যাচাই, দুই passe)।

### ছাপা ১০০
- ছবিতে বাহিত কোনো লেখা বা সংখ্যা নেই; পুরো পাতাই ছাপা লেখা ও অঙ্ক।

## ⛔ উৎস-সীমা

১. **ছাপা ১০০** — একই পাতায় **তিনটি আলাদা "যোগ করি" ব্লক**, প্রতিটির ক্রম আবার (১) থেকে শুরু। কেবল "ছাপা ১০০, ক্রম ৩" বলে কোনো প্রশ্ন চিহ্নিত করা যায় না; ব্লকও উল্লেখ করতে হবে। একই ধাঁচ ছাপা ৯৭ ও ৯৮-এও (প্রতিটিতে নিজস্ব (১)–(৬) ক্রম)।

২. **ছাপা ৯৮** — উল্লম্ব ছকে যোগফল ৫ ৭ ছাপা আছে, অথচ পাশের "৪১ + ১৬ = [ ]" ঘরটি ফাঁকা। একই যোগের উত্তর একই পাতায় একবার ছাপা, একবার ফাঁকা।

৩. **ছাপা ৯৭** — "৩০ + ২০ = [ ]" ও "[ ] টি খাতা" দুটি আলাদা ফাঁকা ঘর একই উত্তরের জন্য; স্থানীয় মানের ছকের একক কলাম দুই সারিতেই খালি, শূন্য বোঝাতে কোনো চিহ্ন ছাপা হয়নি।

৪. **ছাপা ১০০** — শেষ দুটি শব্দ-সমস্যার কোনো ক্রমিক নম্বর ছাপা নেই, উত্তর লেখার জায়গাও ছাপা নেই।

৫. **ছাপা ৯৭–১০০** — ছাপা ৯৮-এর উল্লম্ব ছকের ৫ ৭ ছাড়া এই অধ্যায়ের **কোনো যোগফল বইয়ে ছাপা নেই**। এই পাতাগুলো থেকে প্রশ্ন তৈরি করলে উত্তর বইয়ের কর্তৃত্বে নয়।
