# C1 গণিত — অধ্যায় ৯: সংখ্যা (২১ থেকে ৪০)

**অবস্থা:** নির্মাণাধীন (খসড়া — মানব-যাচাই বাকি)

## পরিসর

- ছাপা: ৬৯–৭৩ (কর্তৃত্বপূর্ণ)
- PDF (split-ফাইল): ৭১–৭৫ — এই আপলোড করা ফাইলের নিজস্ব পৃষ্ঠা-সংখ্যা
- PDF (পূর্ণ বই): অজানা — মূল বইয়ের offset পৃথকভাবে নির্ণেয়

## উৎস-নোট

- ফাইলটি পূর্ণ বইয়ের একটি split (৮৩ পৃষ্ঠা, ছাপা ১–৮১)। এই ফাইলের offset: ছাপা = PDF − ২।
- ফাইলে কোনো text layer নেই — পুরোটাই raster; দ্বিতীয় চ্যানেল নেই।
- প্রতি পাতার প্রান্তে উল্লম্বভাবে ছাপা: ২০২৬। চলতি শিরোনাম বাম পাতায় "সংখ্যা (২১ থেকে ৪০)"; ছাপা ৭০-এর ছকের নিজস্ব শিরোনাম "সংখ্যা : ৩১ থেকে ৪০ পর্যন্ত"।
- **গণনার পদ্ধতি:** ছাপা ৬৯ ও ৭০-এর "গণনা করি" কলামের প্রতিটি ঘর ৫০০ dpi-তে আলাদা করে ক্রপ করে (ছকের রেখা স্বয়ংক্রিয়ভাবে শনাক্ত করে) দুইবার গণনা করা হয়েছে — একবার সারি-বরাবর, একবার পুনরায় ক্রপ পড়ে। প্রথম পাসে পাতা-দৃশ্য থেকে ২৩-সারিকে ভুলভাবে ২৬ পড়া হয়েছিল; বিবর্ধিত ক্রপে সেটি সংশোধিত হয় (৭ + ৭ + ৯)। **পাতা-দৃশ্য থেকে এই বৃত্ত-গুচ্ছ গোনা নির্ভরযোগ্য নয়** — যাচাইকারীর জন্য নোট।
- ছাপা ৬৯ ও ৭০-এর প্রতি সারিতে ছাপা "২ দশ ১" / "২১" ইত্যাদি একটি স্বাধীন ছাপা চ্যানেল; নিচের সব গণনা সেই ছাপা সংখ্যার সাথে মিলেছে।

## পাঠ্য

### ছাপা ৬৯

চলতি শিরোনাম: সংখ্যা (২১ থেকে ৪০)

- সংখ্যা (২১ থেকে ৪০)

ছক — কলাম শিরোনাম: গণনা করি | দশের সাহায্যে গণনা করি | দশের সাহায্যে পড়ি | সংখ্যা পড়ি | সংখ্যা লিখি

| দশের সাহায্যে পড়ি (ছাপা) | সংখ্যা পড়ি (ছাপা) |
|---|---|
| ২ দশ ১ | ২১ · একুশ |
| ২ দশ ২ | ২২ · বাইশ |
| ২ দশ ৩ | ২৩ · তেইশ |
| ২ দশ ৪ | ২৪ · চব্বিশ |
| ২ দশ ৫ | ২৫ · পঁচিশ |
| ২ দশ ৬ | ২৬ · ছাব্বিশ |
| ২ দশ ৭ | ২৭ · সাতাশ |
| ২ দশ ৮ | ২৮ · আটাশ |
| ২ দশ ৯ | ২৯ · উনত্রিশ |
| ৩ দশ | ৩০ · ত্রিশ |

কাজ: বাম কলামের ছড়ানো বৃত্ত গণনা, দশের গুচ্ছ হিসেবে একই সংখ্যা পড়া, সংখ্যা পড়া ও লেখা।
"সংখ্যা লিখি" কলাম (রুল ৯ অনুযায়ী বর্ণনা): কেবল প্রথম সারিতে (২১) দুইটি নমুনা ঘর — একটিতে তীরচিহ্নসহ রেখা-নির্দেশক, একটিতে বিন্দু-রেখার ট্রেসিং। বাকি নয় সারির দুইটি ঘরই সম্পূর্ণ ফাঁকা।
ছবি: বাম কলামে ছড়ানো ফাঁকা বৃত্ত; মাঝের কলামে ত্রিভুজাকৃতির দশ-গুচ্ছ ও অতিরিক্ত বৃত্ত।

### ছাপা ৭০

চলতি শিরোনাম: প্রাথমিক গণিত

- সংখ্যা : ৩১ থেকে ৪০ পর্যন্ত

ছক — কলাম শিরোনাম ছাপা ৬৯-এর অনুরূপ। ছকের রেখা কমলা রঙে ছাপা (ছাপা ৬৯-এ কালো)।

| দশের সাহায্যে পড়ি (ছাপা) | সংখ্যা পড়ি (ছাপা) |
|---|---|
| ৩ দশ ১ | ৩১ · একত্রিশ |
| ৩ দশ ২ | ৩২ · বত্রিশ |
| ৩ দশ ৩ | ৩৩ · তেত্রিশ |
| ৩ দশ ৪ | ৩৪ · চৌত্রিশ |
| ৩ দশ ৫ | ৩৫ · পঁয়ত্রিশ |
| ৩ দশ ৬ | ৩৬ · ছত্রিশ |
| ৩ দশ ৭ | ৩৭ · সাঁইত্রিশ |
| ৩ দশ ৮ | ৩৮ · আটত্রিশ |
| ৩ দশ ৯ | ৩৯ · ঊনচল্লিশ |
| ৪ দশ | ৪০ · চল্লিশ |

কাজ: ছাপা ৬৯-এর ধারাবাহিকতা, ৩১ থেকে ৪০।
"সংখ্যা লিখি" কলাম: কেবল প্রথম সারিতে (৩১) দুইটি নমুনা ঘর; বাকি নয় সারি ফাঁকা।
ছবি: বাম কলামে ছড়ানো বৃত্ত; মাঝের কলামে তিনটি (শেষ সারিতে চারটি) দশ-গুচ্ছ ও অতিরিক্ত বৃত্ত।

### ছাপা ৭১

চলতি শিরোনাম: সংখ্যা (২১ থেকে ৪০)

- দশের গুচ্ছ তৈরি করে গণনা করি ও খালি ঘরে সংখ্যা লিখি।
- তোমার বাড়িতে, শ্রেণিকক্ষে, বিদ্যালয়ের বিভিন্ন জিনিস ৪০টির মধ্যে থাকলে তা গণনা করো ও বলো।

কাজ: পনেরোটি ঘরে ছড়ানো বৃত্ত দশের গুচ্ছ বানিয়ে গণনা করে পাশের খালি ঘরে সংখ্যা লিখতে হবে। প্রথম ঘরে নমুনা — দশটি বৃত্তের চারপাশে লাল দাগ টানা ও উত্তর **১৪** ছাপা; বাকি চোদ্দোটি ঘরের উত্তর ফাঁকা।
ছবি: পাঁচ সারি × তিন কলামের কমলা-রেখার ছকে ছড়ানো ফাঁকা বৃত্ত; নিচে টিয়া পাখি।

### ছাপা ৭২

চলতি শিরোনাম: প্রাথমিক গণিত

- সংখ্যা কথায় লেখা (১ থেকে ১০)

ছক — কলাম শিরোনাম: গণনা করি | পড়ি | কথায় লিখি

| ছাপা সংখ্যা | ছাপা শব্দ |
|---|---|
| ১ | এক |
| ২ | দুই |
| ৩ | তিন |
| ৪ | চার |
| ৫ | পাঁচ |
| ৬ | ছয় |
| ৭ | সাত |
| ৮ | আট |
| ৯ | নয় |
| ১০ | দশ |

কাজ: বাম কলামের ছবি গণনা, সংখ্যা পড়া, ও "কথায় লিখি" কলামে শব্দটি বিন্দু-রেখা ধরে লেখা। "কথায় লিখি" কলামের ডান ঘরে প্রতিটি শব্দের **বিন্দু-রেখার (dotted) ট্রেসিং নমুনা** ছাপা; নিজে লেখার জন্য আলাদা ফাঁকা ঘর নেই।
ছবি: গণনা-কলামে প্রতি সারিতে ১ থেকে ১০টি লাল-হলুদ মার্বেল-সদৃশ গোলক।

### ছাপা ৭৩

চলতি শিরোনাম: সংখ্যা (২১ থেকে ৪০)

- অঙ্কে লেখা সংখ্যার সাথে কথায় লেখা সংখ্যা দাগ টেনে মিল করি
- সংখ্যা কথায় লিখি

মিলকরণ ছক (দুই অংশ; প্রতি অংশে বাম কলাম "সংখ্যা অঙ্কে", ডান কলাম "সংখ্যা কথায়"):

| বাম অংশ — অঙ্ক | বাম অংশ — কথায় |
|---|---|
| ২ (এখান থেকে "দুই"-এ নমুনা দাগ টানা) | এক |
| ৫ | চার |
| ১ | দুই |
| ৪ | সাত |
| ৭ | পাঁচ |

| ডান অংশ — অঙ্ক | ডান অংশ — কথায় |
|---|---|
| ৩ | নয় |
| ৯ | আট |
| ৬ | দশ |
| ১০ | তিন |
| ৮ | ছয় |

"সংখ্যা কথায় লিখি" — দুই অংশে ত্রিভুজের ভিতরে ছাপা সংখ্যা ও পাশে ফাঁকা রেখা:
- বাম: ৩ · ৭ · ২ · ৫ · ৮
- ডান: ১ · ৬ · ১০ · ৯ · ৪

কাজ: অঙ্ক ও শব্দ দাগ টেনে মেলানো (বাম অংশে একটি নমুনা দাগ, বাকি নয়টি খালি); তারপর দশটি সংখ্যা কথায় লেখা।

## চিত্র-বাহিত লেখা (raster-only)

নিচের পরিমাণগুলো কেবল ছবিতে আছে — একক-চ্যানেল পাঠ; প্রতিটি ৫০০ dpi-তে ঘর-ভিত্তিক ক্রপে দুইবার গণনা করা, এবং প্রতিটি পাশের ছাপা সংখ্যার সাথে মিলেছে।

**ছাপা ৬৯ — "গণনা করি" কলাম** (উপরের সারি থেকে নিচে)

| সংখ্যা | বৃত্তের সজ্জা |
|---|---|
| ২১ | ৭ + ৬ + ৬ + ২ |
| ২২ | ৬ + ৮ + ৮ |
| ২৩ | ৭ + ৭ + ৯ |
| ২৪ | ৭ + ৮ + ৯ |
| ২৫ | ৮ + ৮ + ৯ |
| ২৬ | ৯ + ৮ + ৯ |
| ২৭ | ২ + ৮ + ৮ + ৯ |
| ২৮ | ৩ + ৮ + ৯ + ৮ |
| ২৯ | ১০ + ৯ + ১০ |
| ৩০ | ১০ + ১০ + ১০ |

**ছাপা ৬৯ — "দশের সাহায্যে গণনা করি" কলাম:** প্রতি সারিতে দুইটি ত্রিভুজাকৃতি দশ-গুচ্ছ (প্রতিটি ১ + ২ + ৩ + ৪) এবং পাশে যথাক্রমে ১, ২, ৩, ৪, ৫, ৬, ৭, ৮ ও ৯টি অতিরিক্ত বৃত্ত; শেষ সারিতে (৩০) অতিরিক্ত বৃত্তের বদলে **তৃতীয় একটি পূর্ণ দশ-গুচ্ছ**।

**ছাপা ৭০ — "গণনা করি" কলাম** (সব সারিতে একই কাঠামো)

| সংখ্যা | বৃত্তের সজ্জা |
|---|---|
| ৩১ | ১ + ১০ + ১০ + ১০ |
| ৩২ | ২ + ১০ + ১০ + ১০ |
| ৩৩ | ৩ + ১০ + ১০ + ১০ |
| ৩৪ | ৪ + ১০ + ১০ + ১০ |
| ৩৫ | ৫ + ১০ + ১০ + ১০ |
| ৩৬ | ৬ + ১০ + ১০ + ১০ |
| ৩৭ | ৭ + ১০ + ১০ + ১০ |
| ৩৮ | ৮ + ১০ + ১০ + ১০ |
| ৩৯ | ৯ + ১০ + ১০ + ১০ |
| ৪০ | ১০ + ১০ + ১০ + ১০ |

*অভ্যন্তরীণ সঙ্গতি:* ছাপা ৭০-এর দশটি ঘরই একই নিয়মে আঁকা — উপরের সারিতে (সংখ্যা − ৩০)টি বৃত্ত, নিচে তিন সারিতে ১০টি করে। ছাপা ৬৯-এর সজ্জা অনিয়মিত, প্রতিটি আলাদা করে গোনা।

**ছাপা ৭০ — "দশের সাহায্যে গণনা করি" কলাম:** প্রতি সারিতে তিনটি দশ-গুচ্ছ ও পাশে যথাক্রমে ১–৯টি অতিরিক্ত বৃত্ত; শেষ সারিতে (৪০) **চতুর্থ একটি পূর্ণ দশ-গুচ্ছ**।

**ছাপা ৭১ — পনেরোটি ঘরের বৃত্ত-গণনা** (সারি অনুসারে, বাম থেকে ডানে)

| | কলাম ১ | কলাম ২ | কলাম ৩ |
|---|---|---|---|
| সারি ১ | **১৪** (উত্তর ছাপা; লাল দাগে ঘেরা ১০ + বাইরে ৪) | ২০ | ৩৩ |
| সারি ২ | ১৬ | ২৮ | ১৬ |
| সারি ৩ | ১২ | ২৫ | ৩৯ |
| সারি ৪ | ১১ | ১৯ | ১৪ |
| সারি ৫ | ১৭ | ২৯ | ৩৭ |

প্রতিটি ঘর ৬০০ dpi-তে ছকের রেখা শনাক্ত করে আলাদা ক্রপে দুইবার গণনা করা — একবার অনুভূমিক ব্যান্ড ধরে, একবার বাম-থেকে-ডান অবস্থান অনুসারে; দুই পাসের কোথাও অমিল হয়নি। **তবু ৩৩, ৩৭ ও ৩৯ — এই তিনটি ঘন ঘরে যাচাইকারীর বিশেষ মনোযোগ প্রয়োজন**, কারণ এখানে কোনো ছাপা প্রতি-চ্যানেল নেই।

**ছাপা ৭২** — গণনা-কলামে গোলকের সংখ্যা সারি অনুসারে ১, ২, ৩, ৪, ৫, ৬, ৭, ৮, ৯, ১০; প্রতিটি পাশের ছাপা সংখ্যার সাথে মিলেছে।

**অন্যান্য**

- ছাপা ৬৯–৭৩ · প্রান্তে উল্লম্বভাবে ছাপা: ২০২৬

## ⛔ উৎস-সীমা

১. **ছাপা ৭১ — গণনা কেবল ছবিতে, এবং মান অধ্যায়ের পরিসরের বাইরে।** পনেরোটি ঘরের মধ্যে কেবল প্রথমটির উত্তর (১৪) ছাপা; বাকি চোদ্দোটির সংখ্যা কেবল আঁকা বৃত্তে বিদ্যমান — কোনো ছাপা প্রতি-চ্যানেল নেই। তার উপর অধ্যায়ের শিরোনাম "সংখ্যা (২১ থেকে ৪০)" হলেও গোনা পনেরোটি মানের মধ্যে **সাতটি ২১-এর নিচে** (১১, ১২, ১৪, ১৪, ১৬, ১৬, ১৭, ১৯, ২০) এবং কোনোটিই ৪০ নয়; দুইটি মান (১৪ ও ১৬) দুইবার করে আছে।
২. **ছাপা ৭২ — অধ্যায়ের পরিসরের বাইরের পাতা।** পাতার নিজস্ব শিরোনাম "সংখ্যা কথায় লেখা (১ থেকে ১০)" এবং ছাপা ৭৩-এর মিলকরণ ও কথায়-লেখা দুইটিই ১–১০ নিয়ে — অথচ দুইটি পাতাই "সংখ্যা (২১ থেকে ৪০)" অধ্যায়ের ভিতরে, চলতি শিরোনামও তাই। অধ্যায়ের ঘোষিত পরিসরের সাথে ছাপা ৭২–৭৩-এর বিষয়বস্তুর মিল নেই।
৩. **ছাপা ৭২ — নিজে লেখার ঘর নেই।** "কথায় লিখি" কলামে কেবল বিন্দু-রেখার ট্রেসিং নমুনা ছাপা; শব্দটি নিজে লেখার জন্য কোনো ফাঁকা ঘর বা রেখা নেই।
৪. **ছাপা ৬৯ ও ৭০ — লেখার ফাঁকা ঘর প্রায় নেই।** "সংখ্যা লিখি" কলামে কেবল প্রথম সারিতে নমুনা (তীর-নির্দেশক ও বিন্দু-রেখা) ছাপা; বাকি নয় সারির ঘর ফাঁকা থাকলেও কোনো নমুনা বা নির্দেশ নেই — অর্থাৎ ২২–৩০ ও ৩২–৪০ সংখ্যাগুলোর লেখার কোনো রূপরেখা বইয়ে নেই। (অধ্যায় ৬-এর ছাপা ৫৪–৫৫-এ প্রতি সারিতে নমুনা ছিল কিন্তু ফাঁকা ঘর ছিল না; এখানে উল্টোটা।)
