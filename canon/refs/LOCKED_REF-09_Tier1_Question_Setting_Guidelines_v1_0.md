# Tier 1 Question-Setting Guidelines

**REF-09 · v1.0 · the minimum question-setting standard for every teacher**

**Purpose.** The floor that *every* teacher meets, *every* time they write a question — for a per-chapter class test, a half-yearly or annual exam, a homework Pool item, or a practice worksheet. Tier 1 is the standard below which no question in the school should fall. It is not the ceiling: the higher standard — scholarship, Britti, Olympiad, and top-school admission patterns — is **Tier 2 (REF-10)**, which builds on this document once it is locked.

**What this document does *not* cover — read REF-17 instead.** Tier 1 does **not** re-teach Bloom's. For the six levels and how to tell them apart, the master verb and stem banks, the per-class Bloom bands, the lesson ladder, the **question-paper blueprint method**, **MCQ construction**, **creative-question construction**, and the **per-subject patterns** → use **REF-17 (V1B Standard Reference)** at the desk, or **REF-18 (V1C Daily-Use Pocket)** in a production chat. This document points to REF-17; it does not restate it.

**What Tier 1 owns (distinct from REF-17).**
- The **per-teacher minimum bar** — the contract every question and every question-set must satisfy.
- **Difficulty calibration** — the easy/medium/hard axis, which is *separate* from the Bloom's level axis.
- **Exact paper structures and mark splits** — the concrete numbers REF-17 §5.2 deliberately defers to "the Tier 1 / Tier 2 question-setting guidelines."
- The **mandatory answer-key and rubric standard** — no question leaves a teacher's hand without one.
- The **weak-student practice volume** floor.
- The **Subject-Lead Review Gate** — the formal check a question-set passes before it is used.

**Authority note.** Where this and a fuller reference differ: Bloom bands defer to **REF-06 §3.6**; chapter-vs-session scope defers to **REF-02 v1.3 (§2.3 / §2.9)**; what content must be replaced or kept defers to **REF-01 (Islamic Curation Policy)**; English vocabulary defers to **REF-22**; the revision spiral and the homework/assignment Pool defer to **REF-07** and **REF-08**. Tier 1 sets the question-setting standard; it does not re-decide those.

## Summary Checklist — The Tier 1 Minimum Bar (every teacher, every time)

| ☐ | Every question carries an **intended Bloom's level** and an **intended difficulty** (level ≠ difficulty — §3). |
| --- | --- |
| ☐ | The set is **not all recall** — it follows the class's Bloom % band (REF-17 §5.2) and reaches the thinking levels that band allows. |
| ☐ | The set spans **all three difficulty bands** so the weakest student can attempt the foundation and the strongest is stretched (§3, §6). |
| ☐ | A **paper / class test is blueprinted before it is written** (REF-17 §7.1), and column totals match the class band (§4). |
| ☐ | **Every** question has a written **answer key or rubric** — including open-ended items (§5). |
| ☐ | Every question is **curation-clean** — F-01 names, no flagged content; example contexts honour Islamic values (§7). |
| ☐ | At least some items are **free-thinking** (Analyze/Evaluate/Create), framed inside revealed guidance, not "say anything you like" (§7). |
| ☐ | The set passes a **self-check**, a **peer check**, and the **Subject-Lead Review Gate** before use (§8, §9). |

## §1 — What Tier 1 Is, and Who It Binds

Tier 1 exists because question quality in the school varies as widely as teaching quality does (Strategic Context, problems 3 and 7): some teachers test only memory, some misjudge difficulty, some write questions a chapter never taught, and homework, class tests, and exams do not always align. Tier 1 is the **single floor** that closes that gap.

**It binds every teacher, for every assessable question they author:**
- the per-chapter **class test** (the REF-07 checkpoint and chapter-stop gate);
- the **half-yearly** and **annual** exams (the two REF-07 maintenance horizons);
- **homework Pool** items (REF-08; minimum 20 per chapter);
- **practice worksheets** and weak-student top-up sets (REF-07 §4.1).

It does **not** lower the bar for younger classes — it scales the *level and difficulty* to the class (§3, §4), not the *care*. A Class 1 question is held to Tier 1 exactly as a Class 5 question is.

**One rule above all others — alignment (সামঞ্জস্য).** A question must test what was actually taught, at a level the teaching prepared. Teaching at Remember and testing at Analyze is unfair; teaching deeply and testing only memory teaches students that depth does not count. Lesson plan ↔ question ↔ homework must point at the same learning outcome (REF-02 §2; REF-08).

## §2 — The Seven Musts

Every Tier 1 question must satisfy all seven. A set is only Tier 1 if **each** of its questions passes and the **set as a whole** passes the balance musts (5–6).

1. **Curriculum-true.** It tests content the chapter actually contains, mapped to the chapter's learning outcome (the TG-reconciled যোগ্যতা/শিখনফল on the skeleton).
2. **Level-labelled.** It carries one intended Bloom's level, and the *mental work* matches that level (REF-17 §2, §11). A high-level verb on a recall task is not high-level.
3. **Difficulty-labelled.** It carries one intended difficulty — easy / medium / hard — set independently of the Bloom's level (§3).
4. **Answerable from teaching.** A student who learned the chapter can reach the answer; nothing depends on un-taught knowledge or a trick.
5. **Set-balanced for level.** Across the set, the Bloom mix sits inside the class's % band (REF-17 §5.2): not all Remember, and reaching the thinking levels the band allows.
6. **Set-balanced for difficulty.** Across the set, all three difficulty bands appear so weak, average, and strong students each have appropriate work (§3, §6).
7. **Keyed.** It has a written answer key (closed) or a criteria rubric (open), prepared *at the same time as the question*, never after (§5).

## §3 — Difficulty Calibration (the Second Axis)

Bloom's level and difficulty are **two different axes**, and the most common Tier-1 error is to confuse them. A Remember question can be hard ("Recite the seven heavens in order"); an Analyze question can be easy ("Which of these two pictures shows sharing? Why?"). Set **both** on purpose.

**The three difficulty bands:**

| Band | Bangla | What makes it this band | Who must be able to do it |
| --- | --- | --- | --- |
| **Easy (সহজ)** | foundation | direct, single-step, familiar wording, taught example reused | **every** student who attended the chapter |
| **Medium (মাঝারি)** | standard | one step removed — new numbers/context, two-step reasoning, slight rewording | the **average** student |
| **Hard (কঠিন)** | stretch | unfamiliar context, multi-step, combines ideas, demands justification | the **stronger** student; weak students attempt for partial credit |

**What moves a question's difficulty (independent of Bloom's level):** familiarity of the context · number of steps · how much the wording resembles the taught example · how much must be held in mind at once · how much is given vs. must be supplied.

**The Tier 1 difficulty floor for any class test or exam:**
- **Easy ≥ 30%** of marks — so the weakest attending student can always reach a pass on the foundation. This is non-negotiable for a school with many weak students.
- **Hard ≤ 25%** of marks — stretch, not a wall; a paper of mostly hard items punishes the class for the teacher's ambition.
- The remainder is **medium**.
- A reasonable default split is **easy 40% / medium 40% / hard 20%**; a Subject Lead may shift it within the floor/ceiling above, with a one-line logged reason.

**The two axes together — the calibration grid.** When blueprinting (REF-17 §7.1), tag each planned cell with *both* a Bloom's level and a difficulty, then check two totals: the Bloom columns against REF-17 §5.2, and the difficulty split against the floor above. A worked single cell: *Class 3 Math, Apply, Medium* → "A shopkeeper sells 48 eggs in the morning and 37 in the afternoon. How many in all?" (taught operation, new context, one step). Make it *Hard* by adding a second step ("…and 9 break — how many to sell?"); make it *Easy* by reusing the exact taught numbers.

## §4 — Assessment Types and Paper Structures

This section supplies the concrete structures REF-17 §5.2 defers to Tier 1. **Mark totals and durations below are recommended defaults; the school's exam scheme (School Handbook) overrides them — reconcile before locking these as binding (see the dependency note in the version log).** The *structure rules* (sections, balance, keys) are binding regardless of the totals.

### 4.1 Per-chapter class test (the REF-07 checkpoint)
The chapter-stop gate. Short, frequent, low-stakes.
- **Length:** ~15–20 marks, 30–40 minutes.
- **Sections:** a few Remember/Understand items + at least one Apply + (Classes 3–5) one short Analyze/Evaluate item.
- **Difficulty:** easy-leaning (this is a mastery gate, not a ranking) — easy ≥ 40%.
- **Purpose:** decides whether a topic passes to the REF-07 maintenance track; results feed the Class Test Tracker (Project 06).

### 4.2 Half-yearly and annual exams
The two big horizons. Cumulative; blueprinted unit-by-unit (REF-17 §7.1).
- **Length (recommended default, confirm against the exam scheme):** Classes 1–2 lighter (≈50 marks, shorter sitting); Classes 3–5 fuller (up to 100 marks, up to 3 hours).
- **Sections:** MCQ (situation-based, REF-17 §7.2) · short answer · structured/creative (REF-17 §7.3), in proportions that hit the class Bloom band.
- **Difficulty:** the full §3 split, easy ≥ 30% so a prepared weak student passes.
- **Maintenance:** Retained topics get the light pre-exam touch via the weekly assignment (REF-07 §2.4) — the exam must not assume they were re-taught.

### 4.3 Homework Pool items (REF-08)
- **Volume:** minimum **20 questions per chapter** in the Pool (REF-08 §4; reads at chapter scope under D-050).
- **Mix:** spans levels and difficulty so daily homework can draw an appropriate slice within the daily time cap (REF-08 §2); weak-student top-ups are *selected* from this Pool, not newly authored (REF-07 §4.1).
- **Keying:** every Pool item carries its key/rubric in the Pool, so any teacher can mark it.

### 4.4 Practice worksheets
Drill and consolidation, not graded ranking. Easy-and-medium heavy; built for repetition on the foundation (§6).

## §5 — Answer Keys and Rubrics — the Mandatory Standard

**No question is finished until its key is written.** Writing the key *with* the question is the cheapest quality check there is: a question you cannot key cleanly is ambiguous, mis-levelled, or un-taught.

**Closed questions (one correct answer).** The key states: the correct answer · the marks · for multi-step items, the **mark breakdown by step** (so partial credit is consistent across markers — this directly addresses weak script-checking, Strategic Context problem 4). MCQ keys also name *why each distractor is wrong* (REF-17 §7.2), so re-use and review are faster.

**Open-ended questions (more than one valid answer).** These **must** carry a **criteria rubric**, never a single model answer. Use the locked Tier-1 rubric shape (REF-17 §9):

| Criteria | 4 | 3 | 2 | 1 |
| --- | --- | --- | --- | --- |
| Content accuracy | fully accurate | mostly | some correct | mostly incorrect |
| Reasoning | clear reasons + evidence | limited | weak | none |
| Organization | well organised | mostly | some structure | disorganised |
| Islamic / moral alignment | fully appropriate | mostly | needs correction | inappropriate |

Scale the row count to the marks (a 4-criteria rubric reads naturally to 10 or to a 4-band total; drop the Organization row for very young classes). The **Islamic/moral alignment row is required** on any value-touching open item.

**Standard format for a keyed item (use this layout):** *question text · class · subject · chapter · intended Bloom's level · intended difficulty · marks · answer key OR rubric.* The last six fields are the Tier-1 metadata every item carries through to the Project 04 bank.

## §6 — Weak-Student Practice Volume

The school's weak students fail not from one missed lesson but from **too little practice on the foundation**. Tier 1 sets a volume floor so practice exists before it is needed.

- **Per chapter, the Pool (REF-08) carries ≥ 20 questions**, of which a clear majority are **easy/medium foundation** items — enough that a struggling student can be given repeated, varied practice on the same outcome without running out.
- **Load-bearing topics get more.** Where REF-19 / REF-03 mark a topic 🔴 High load-bearing, the Pool carries a **deeper easy/medium bench** for it, because failure there weakens future years (REF-19 §4). Low/terminal topics need fewer.
- **Top-ups are reactive and bounded.** When the tracker flags a weak pupil, the teacher *selects* extra items from the existing Pool (REF-07 §4.1) — never invents them on the spot, never an unbounded pile.
- **Repetition with variation, not repetition identical.** Re-practice changes the numbers/context (an §3 *Easy* re-skin), so the student practises the method, not a memorised answer.

This is also where free thinking reaches weak students: a simple Evaluate item ("Was it kind that Ayesha shared? Why?") is *easy difficulty* yet *high Bloom's* — it builds reasoning without a heavy reading load.

## §7 — Curation, Free Thinking, and Vocabulary Compliance

A question is school-content like any other, so it passes the same gates.

**Curation (REF-01).** Every question and its context is **F-01-clean**: personal names from the approved pool (REF-20), no content flagged by REF-01 (music/dance/festival framings, other-faith devotional content, problematic depictions, riba, etc.). When a chapter's own content is flagged NEEDS-REPLACEMENT on the annotated skeleton, the question uses the **replacement** content, not the original. Contexts are drawn from Islamic family life, prophetic narrations, adab, signs of Allah in nature, and halal occupations (Project 00 §7).

**Free thinking (স্বাধীন চিন্তা), framed.** Tier 1 requires at least some Analyze/Evaluate/Create items in any class-test or exam set the band allows — but **framed inside revealed guidance** (REF-17 §9): open the door, then anchor it. Not "say anything about salah," but "explain how salah builds discipline, with examples." Free thinking and adab strengthen each other; "free" means *reasoned and responsible*, not careless.

**Vocabulary — English only (REF-22).** English questions use **operative vocabulary = Core + Working + already-taught** words; a comprehension passage may carry Receptive words **only if** they are pre-taught/glossed in the item (REF-22 §0.2). This keeps questions answerable rather than blocked by an unknown word.

## §8 — The Setting Workflow (stepwise)

Follow these steps in order for any class test or exam. (For a single homework Pool item, steps 4–7 apply.)

1. **Anchor.** Open the chapter's skeleton row and its TG-reconciled learning outcome(s). Note any NEEDS-REPLACEMENT flags — you will use replacement content.
2. **Blueprint.** Build the grid (REF-17 §7.1): units down the side, marks per unit by teaching weight, marks split across Bloom's levels to the class band (REF-17 §5.2).
3. **Calibrate.** Tag each blueprint cell with a **difficulty** too (§3); check the difficulty split against the floor (easy ≥ 30%, hard ≤ 25%).
4. **Write.** Fill each cell with a question whose *mental work* matches its level and difficulty (REF-17 §2, §7.2, §7.3). Apply curation and vocabulary as you write (§7).
5. **Key.** Write the answer key or rubric for each item *now*, in the standard format (§5).
6. **Self-check.** Run the item through the §2 seven musts and REF-17 §11 (the ten misconceptions). Fix mis-levelling, ambiguity, and un-taught dependencies.
7. **Peer-check.** A colleague runs REF-17 §10's quick checks and the §9 gate below; feedback is specific ("this tests only recall — add a situation"), not "good/bad."
8. **Submit to the Subject Lead.** With the §9 submission packet. The set is **not used until the gate passes**.

## §9 — The Subject-Lead Review Gate + Reviewer Checklist

Tier 1's quality is only real if something checks it before students see it. The **Subject Lead (বিষয় সমন্বয়কারী)** is that gate. No class-test or exam set is used until it passes; homework Pools are gated at chapter-build time.

**What the teacher submits (the packet — extends REF-17 §10):** class · subject · chapter · the **blueprint** (with Bloom and difficulty totals) · the question set · the **keys/rubrics** · any specific concern ("is item 7 too hard for Class 4?").

**Reviewer Checklist — the Subject Lead runs every item and the set through this. A "No" sends the item back.**

| # | Check | Pass? |
| --- | --- | --- |
| 1 | Each question maps to a chapter learning outcome (curriculum-true). | ☐ |
| 2 | Each question's **Bloom's level label matches its mental work** (not just its verb). | ☐ |
| 3 | Each question's **difficulty label is right**, and is set independently of its level. | ☐ |
| 4 | A student who was taught the chapter can answer it (nothing un-taught, no trick). | ☐ |
| 5 | Language is age-appropriate; the item is free of ambiguity. | ☐ |
| 6 | **Every** item has a written key or rubric in standard format; multi-step keys break marks by step. | ☐ |
| 7 | The set's **Bloom mix** sits inside the class band (REF-17 §5.2) — not all recall. | ☐ |
| 8 | The set's **difficulty mix** meets the floor (easy ≥ 30%, hard ≤ 25%). | ☐ |
| 9 | At least some items are **free-thinking**, framed inside Islamic guidance. | ☐ |
| 10 | Every item is **curation-clean** (F-01 names, no flagged content, replacement content where flagged). | ☐ |
| 11 | (English) Vocabulary is Core + Working + already-taught; any Receptive word is glossed in the item. | ☐ |
| 12 | Lesson ↔ question ↔ homework **align** on the same outcome. | ☐ |

**On a "No":** the Subject Lead names the item, the failed check, and a concrete fix — the same respectful, specific register peer review uses. The aim is a better question, not a verdict on the teacher.

## §10 — Ready-Check (before any set is submitted)

- ☐ Blueprint filled **before** writing; Bloom totals match the class band; difficulty split meets the §3 floor.
- ☐ Every item carries **both** labels — Bloom's level **and** difficulty — and the mental work matches the level.
- ☐ Every item has a **key or rubric** in standard format; open items use the criteria rubric with the Islamic-alignment row.
- ☐ The set is **curriculum-true** and **answerable from teaching** — nothing un-taught, no trick.
- ☐ At least some **free-thinking** items, framed inside revealed guidance.
- ☐ Curation-clean and (English) vocabulary-clean.
- ☐ Self-checked, peer-checked, and ready for the **Subject-Lead gate**.
