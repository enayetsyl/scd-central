## §0 — Summary and scan checklist (read this first)

**What this document is.** A trigger-recognition watch-list (§3) plus a mandatory scan procedure (§2) that together stop curation misses of the kind the Class 1 Bangla pilot produced. That pilot was first annotated from the skeleton, the Teacher Guide, and a few sample pages, and wrongly reported "0 forced replacements." A full page-by-page rescan found **14 divisions with forced element-level replacements + 4 borderline items** — all hidden in *example words, practice sentences, counting items, and illustrations*, never in lesson themes (Appendix A). REF-21 generalizes that lesson so no future subject repeats it.

**The one-sentence rule.** *The textbook page is the curation surface — not the skeleton, not the Teacher Guide, not a sample.* You must read every page, every element, against the lexicon, with a separate pass for pictures, and prove it with a ledger.

**Scan checklist (run for every annotated-skeleton chat):**

- [ ] **Build the subject extension first** (§4) — list which REF-01 categories surface most in *this* subject's content type before scanning.
- [ ] **Read every page, element by element** (§2 step 1–2) — title · each example word · each practice/decoding sentence · each exercise/matching/fill-in/counting item · each illustration.
- [ ] **Run the separate illustration pass** (§2 step 3) — images trigger C-02/C-03/C-04/C-05/C-18 independent of clean text.
- [ ] **Grep every element against the lexicon** (§3) and against REF-01's flags F-01/F-03/F-04/F-05/F-06.
- [ ] **Record the per-division scan ledger with a completeness assertion** (§2 step 4) — every division `scanned ✓ (page nn)` + element counts. Spot-checking or inferring "formulaic" divisions is prohibited.
- [ ] **Write a per-element replacement spec** for each NEEDS-REPLACEMENT item (§6) — the structured brief Project 05 will build from.
- [ ] **Compile the Borderline / Escalation register** (§2 step 5) and get the Principal's ruling **before the skeleton locks** (§2 step 6).
- [ ] **Capture each Principal ruling as a REF-01 edge-case proposal** (§7) so the same ambiguity is never escalated twice.

## §1 — Purpose, scope, and where it loads

### 1.1 Purpose
REF-01 tells an annotator *what* conflicts with the school's Islamic commitments and *what to preserve* when replacing it. It cannot, by itself, guarantee the annotator *finds* every conflict — because most conflicts at the primary level are not lesson themes but single words and single pictures. REF-21 closes that gap: a recognition watch-list plus a procedure rigorous enough that a second annotator, reading only the ledger, can confirm nothing was skipped.

### 1.2 Scope
Subject-agnostic protocol (§2) + a controlled, growing lexicon (§3) + a per-subject extension rule (§4). The worked instance is Bangla (the pilot subject); other subjects are seeded forward in §4 and filled as each is scanned.

### 1.3 Dual use — scan *and* self-check
REF-21 is used in two directions:
1. **Inbound scan (skeletons).** Find triggers already present in NCTB content. This is the Project 03 annotated-skeleton step.
2. **Outbound self-check (authoring).** A *newly authored* example sentence, question stem, or replacement story can itself re-introduce a trigger — a Western name, a "গান গায়," a creature that "saves a life." Before any lesson plan (Project 03), question pool (Project 04), or replacement piece (Project 05) is finalized, grep the new content against this lexicon too.

### 1.4 Where it sits in the build order
REF-21 governs the **Annotated Skeleton** step of the D-005 chain (Stability Analysis → **Annotated Skeleton** → Replacement Content → Lesson Plans → Question Banks). It does not re-order the chain; it is the **lock-gate** on the annotated-skeleton step — parallel in spirit to the TG-Reconciliation validation gate (D-042). It reads from the completed REF-05 stability skeleton + TG reconciliation, but takes its curation surface from the **actual target-edition textbook**, not from those documents.

## §2 — The Skeleton Scan Protocol (subject-agnostic)

Run these steps in order. None may be skipped, and the skeleton may not lock until step 6 is complete.

**Step 1 — The unit of annotation is the element, not the division.**
Break every division (পাঠ / chapter / unit / dars) into its elements and tag each one independently:
- the **title**;
- **each example word** (every decoding instance, every vocabulary item);
- **each practice / decoding sentence**;
- **each exercise** — matching, fill-in-the-blank, counting, ordering, comprehension prompt;
- **each illustration** (handled again in step 3).
The skeleton (REF-05) and the Teacher Guide supply *objectives*; they do not supply the curation surface.

**Step 2 — Read every page of the actual target-edition textbook.**
Page by page, element by element. The target edition is the one the school will teach (recorded in the skeleton; for current Bangla, the NCF 2021 / পরিমার্জিত edition). Do not infer a page's content from the skeleton's summary or from a "similar" page.

**Step 3 — Run a separate illustration pass.**
After the text pass, sweep the images on their own. An illustration can trigger a category even when the surrounding text is clean: instruments drawn in a room scene (C-03), hero portraits or leader photos (C-18 + C-05), dolls/figurines / পুতুল (C-05), festival decorations (C-04), mixed non-mahram groupings (C-02), or a face where a diagram would serve (চোখ/eye → use an **eye-diagram**, not a face — C-05).

**Step 4 — Grep each element against the lexicon (§3) and record the ledger.**
For every division, fill one ledger row. The ledger is part of the annotated-skeleton file.

| Division | Page(s) | Scanned ✓ | Elements examined (words / sentences / items / images) | Triggers found (C-code · element · tag) | Notes |
|---|---|---|---|---|---|
| পাঠ ৯ | 18–19 | ✓ | 12 / 6 / 3 / 2 | C-03 · "বাঁশি" example word · NEEDS-REPLACEMENT | letter ব intact via clean swap |
| পাঠ ১০ | 20 | ✓ | 9 / 4 / 2 / 1 | — none — | KEEP-AS-IS |

**Completeness assertion (mandatory).** Below the ledger, state in one line: *"All N divisions scanned ✓ page-by-page; M illustrations passed; no division was spot-checked or inferred from theme."* If any division could not be scanned (missing page, illegible scan), say which and why — never silently pass it.

**Step 5 — Compile the Borderline / Escalation register.**
List every element you cannot resolve alone — CASE-BY-CASE items (C-09 ambiguous causation, the residual part of C-10) and OPEN items (C-18 borderline physical acts under REF-01 §5 OPEN-02), plus any cultural-ambiguity item (mythological names, garland/bindi imagery, festival scenes). Do **not** self-resolve these.

| # | Division · page | Element | Why ambiguous (which C · CASE-BY-CASE / OPEN) | Annotator's lean | Principal ruling |
|---|---|---|---|---|---|
| 1 | পাঠ ১৪ · p.27 | "ঐরাবত" (name) | C-01/C-04 — Hindu-mythological elephant; proper-noun watch | replace | _(await ruling)_ |

**Step 6 — Lock-gate.**
The annotated skeleton may not be marked LOCKED, and may not feed Project 05, until: the ledger is complete with its completeness assertion (step 4), the illustration pass is done (step 3), and the Principal has ruled every row of the Borderline register (step 5). A theme-scan or spot-check does not satisfy this gate. (Wire to README §5.3 Draft-vs-Locked.)

> **Extra care on PROTECTED divisions.** Where REF-19's §4A pedagogical-priority axis tags a division 🟦 PROTECTED (free-thinking or Islamic-alignment value), scan and replacement review get the most care — a botched replacement there does the most mission damage.

## §5 — Aqeedah-sensitive vocabulary (teaching-note items)

Some triggers are not "fix the image / swap the word" edits but require a **teaching note** — *what the teacher says* — because the word's everyday usage carries a creed error. Flag these for a note, not only a tag:

- **শহিদ** — only one killed *fī sabīlillāh* (and, by authentic Sunnah, defending life/family/property/faith); never "for the nation." Apply REF-01's locked E-18b teaching-note; the "died-for-the-country = শহিদ" equation is do-not-teach.
- **রিজিক / বাঁচানো / প্রাণ দেওয়া** attributed to a creature or object — reframe (E-09b); for a retained line, a one-sentence note that provision and life are Allah's.
- **ভাগ্য / "luck"** as an autonomous force — reframe to Allah's decree (qadar) where it appears as a cause.

## §6 — Per-element replacement spec (the brief Project 05 builds from)

For **every** element tagged NEEDS-REPLACEMENT, record this five-field spec inside the annotated skeleton. It is the structured input Project 05 authors against and the proof that "outcomes preserved, flesh replaced" was honored.

1. **Trigger** — the REF-01 category (+ flag): e.g. `C-03 / F-05`.
2. **Host element** — title / example word / practice sentence / exercise item / illustration.
3. **What must be preserved** — the target letter/sound · the required vocabulary word (Universal Core / Stable tier, REF-01 §4.3) · the concept · the Bloom's level · the reading level.
4. **Fix** — either the **inline clean substitute** (for a free word/image swap) **or** a **Project 05 pointer** `RC-{SUBJECT}-C{class}-U{nn}[-L{mm}]` (for an authored story/poem/passage).
5. **Names** — any personal-name substitution drawn from **REF-20**, matching class pool (never invented inline).

**Integration map — recognize, then fix:**

```
REF-21 (recognize the trigger, write the spec)
        │
        ├── personal names ──▶ REF-20 (Approved Names Pool, matching class pool)
        ├── stance / edge case ─▶ REF-01 v1.2 (policy: KEEP / FLEXIBLE / REPLACE; E-03/E-09b/E-18b/E-18c)
        └── authored content ──▶ Project 05 (story/poem/example), returned inline with its RC-… ID
```

## §7 — Borderline-ruling feedback loop

Every Principal ruling on a Borderline-register item (§2 step 5) is captured as a **REF-01 edge-case proposal** and routed to Project 02 via a Decision Review Request, exactly as the pilot's four were (E-03, E-09b, E-18b, E-18c). This converts a one-off ruling into reusable policy, so the same ambiguity (e.g. ঐরাবত, garland, festival scene, a borderline civic act) is never escalated twice. Over time the Borderline register for each new subject shrinks as REF-01's §4.5 fills in.
