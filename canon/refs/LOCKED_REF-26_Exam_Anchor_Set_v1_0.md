**What this is:** every item on the 21 finals, distilled into **anchors** — the specific facts and skills a paper actually tested, tagged by format. **The check rule (Conventions v1.4 §9.8a):** when a chapter bank is built, the chat loads this file's lane section, finds every anchor belonging to that chapter, and verifies each is **answerable from the bank**; it prints the coverage table (anchor → covering QID(s) / ❌) in the Review-Gate report. A ❌ is a named flag — it cannot pass silently. **Substrate rule (Principal ruling (a), 2026-07-16):** for a partially-flagged পাঠ the anchors sit on the **textbook minus flagged elements**; only a fully-replaced পাঠ anchors on its replacement content.

**Anchor types:** `F` = fact (the bank must let a student answer this specific content) · `S` = skill (any equivalent item covering the skill passes) · `W` = word-list (the listed words themselves are the anchors) · `ADMIN` = not a bank concern (PAT slot).

The check consumes the lane section current at build time; a bank locked against an older anchor set is re-checked only at its next supersede.
