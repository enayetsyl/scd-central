## §0 — Summary and teacher checklist (read this first)

**What this is.** The single, school-wide routine a teacher follows to handle pictures of living beings and mixed-gender character pairings **at the point of teaching**, so that what reaches the pupil's eyes is consistent with REF-01 (C-05, C-02) without losing any of the lesson's learning content. It comes in **two tiers** — the teacher uses whichever the school's resources allow that term — plus a fallback for any page not yet corrected.

**The one-sentence rule.** *Remove the living-being image and the cross-gender pairing from what the pupil sees, keep everything under the picture, and teach the pupil **why** before the pupil acts.*

**Standing school setting (locked).** The school runs **separate boys' and girls' editions**. The Tier-B rename (B-4) therefore always assigns **same-gender** names — two girls' names in the girls' edition, two boys' names in the boys' edition. There is no per-subject single-edition exception; if a future subject is ever issued as a single shared edition, that is a Decision Review for the Principal, not a teacher-level call.

**Teacher checklist — run before and during the lesson:**

- [ ] **Pick the tier my resources allow.** Clean image sheets supplied for this book? → **Tier A**. None supplied? → **Tier B**.
- [ ] **Tier A:** each pupil glues the clean image over the controversial image **in his/her own book**; the text under the picture is untouched.
- [ ] **Tier B (year's first orientation session):** settle the class → teach the Islamic basis at the pupils' level → pupils obscure every living-being image with **পেনসিল/কলম** (approved pupil materials, D-049), page by page → rename the recurring characters same-gender from REF-20 → overflow becomes homework, checked next class.
- [ ] **Names** come from **REF-20**, matching class pool, matching the edition's gender; pupils choose two by opinion; never reuse one name for both characters; avoid names already used in the lessons.
- [ ] **Any page not yet corrected:** teach **with books closed**, writing the numbers / text / word-problem on the **whiteboard** (হোয়াইটবোর্ড + মার্কার, D-049) for pupils to work from.
- [ ] **Materials gate (REF-11 G2):** only whiteboard + marker for me; only খাতা / পেনসিল / কলম for pupils. Any other surface or tool fails the gate.

## §1 — Purpose, scope, and where it loads

### 1.1 Purpose
REF-01 establishes that pictures of living beings (C-05) and cross-gender character pairings (C-02) are removed. REF-21 ensures every instance is *found* during the skeleton scan. REF-24 closes the last gap: the moment the book is open in front of the pupil, the teacher needs a single, repeatable, dignified routine that takes the offending image and pairing out of view **without** stripping the vocabulary, the concept, the Bloom's level, or the reading content the lesson is built on. "Outcomes preserved, flesh replaced" (Instructions §7) — applied to the physical page.

### 1.2 Scope
School-wide and subject-agnostic. The protocol is identical for Bangla, Math, Science, BGS, English, and every future subject. The recurring-character reference in B-4 is the **only** thing that varies, and it is filled from each book's own skeleton — not from this REF.

### 1.3 Where it loads
- **Project 03 — annotated skeletons:** the skeleton's standing-rules section carries a one-line pointer to REF-24 (§6) instead of an inline protocol.
- **Project 03 — lesson plans:** the **Tier-B orientation session** is authored as the year's first session at the lesson-plan stage (forward pointer — it is *not* built inside the skeleton).
- **Project 05:** authors / sources the Tier-A clean image sheets when the school chooses to supply them.
- **Project 07:** trains teachers on the routine; **REF-11** observes it (G1 curation fidelity, G2 materials).

## §2 — The two-tier protocol (verbatim classroom method)

The teacher uses whichever tier the school's resources allow.

### Tier A — Glue-over *(preferred where the school supplies clean images)*
If the school provides **alternative (clean) images** for each living-being / controversial picture, the **first-week class (and the lower classes generally)** runs a guided task in which **each pupil glues the provided clean image over the controversial image in his/her own book** (ছবির উপর অনুমোদিত ছবি আঠা দিয়ে লাগানো). The content under the picture is unchanged.
*Requires the school to supply the image sheets (Project 05). If not supplied, fall to Tier B.*

### Tier B — Front-matter orientation routine *(where no clean images are supplied)*
Authored as the **year's first orientation session** at the lesson-plan stage (forward pointer — not built in the skeleton). In order:

1. **Orientation & ice-breaking** (পরিচিতি ও সহজ পরিবেশ) — settle the class, build rapport.
2. **Teach the Islamic basis** (ইসলামি ভিত্তি বোঝানো) at a class-appropriate level — *why* we avoid (a) pictures of living beings and (b) cross-gender mixing — **so pupils understand before they act.** This step is mandatory and is the free-thinking core of the routine: the pupil reasons about the rule, not merely obeys it (Instructions §6).
3. **Pupils obscure every living-being image** (প্রতিটি প্রাণীর/মানুষের ছবি ঢেকে দেওয়া) using **পেনসিল/কলম** — approved pupil materials per **D-049** — page by page.
4. **Rename the recurring characters same-gender** (পুনরাবৃত্ত চরিত্রের নাম একই-লিঙ্গে পরিবর্তন). See §3 for the full rule and the per-book character reference.
5. **Time overflow → home task** (সময় না হলে বাড়ির কাজ). If the period does not cover obscuring **all** living-being images, assign the remainder as **homework** and **check it at the start of the next class.**

### Fallback *(either tier, at an uncorrected page)*
Teach **with books closed** (বই বন্ধ রেখে), writing the numbers / text / word-problem on the **whiteboard** (হোয়াইটবোর্ড + মার্কার, D-049) for pupils to work from.

## §3 — The same-gender rename rule (B-4 in full)

**Standing edition rule (locked):** the school runs **separate boys' and girls' editions**, so the rename is always **same-gender**:

- **Girls' edition** — both recurring characters become **two girls' names**.
- **Boys' edition** — both recurring characters become **two boys' names**.

**Procedure:**
1. The teacher **suggests names from REF-20** — the **matching class pool**, **matching the edition's gender**.
2. The class **chooses two by pupil opinion** (মতামতের ভিত্তিতে).
3. **Anti-repetition rule:** do **not** reuse one name for both characters; **avoid** any name already used inside the lessons of this book.

**Character reference (filled per book from its skeleton):** the recurring pair this book actually uses is recorded in **the skeleton's standing-rules / character ledger**, not here. The skeleton states the pair; REF-24 states the method.
- **If the book has no recurring named characters:** mark the rename step **"N/A — no recurring named characters; no rename needed"** and run only B-1, B-2, B-3, and B-5.

**Why this also settles C-02.** Renaming a cross-gender recurring pair to same-gender removes the C-02 mixed-gender pairing at its source. A skeleton's C-02 rule for *recurring characters* therefore points to **"handled by the REF-24 Tier-B rename"** rather than issuing a second, separate instruction — one effective rule, no double-instruction. (C-02 in single-scene, non-recurring contexts is still handled by REF-01's ordinary mahram / single-gender rule.)
