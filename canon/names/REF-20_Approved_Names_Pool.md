## §0 Usage Header & Quick Checklist (read this first)

**What this is.** A pool of vetted Bengali-Muslim personal names, organised one pool per class (C1–C5), each split into a **Male** and a **Female** list, for use whenever C-10/F-01 requires a Western or non-Muslim personal name to be replaced in NCTB-derived content.

**60-second checklist — picking a name:**
1. **Match the class.** Use the pool for the class you are writing for.
2. **Match the character's gender** to the Male or Female list.
3. **Use the বাংলা column verbatim** — it is the authoritative form that goes into student-facing text. The Roman column is a teacher aid; the উৎস (source) column is teacher-facing only and **never** appears in student material.
4. **Do not over-repeat within one lesson set.** Across a single lesson / story / exercise set, vary the names — do not reuse the same name for two characters, and rotate names across the lessons of one unit so a class does not meet "আনাস" in every story.
5. **Preserve the C-10 outcome.** Swapping the name must not change the learning outcome, the required vocabulary, the Bloom's level, or the reading difficulty (REF-01 §4.2–§4.4).
6. **If you need a name not here,** prefer extending this file (see §5) over inventing ad hoc, so the school's pool stays consistent and vetted.

**Naming convention used in this file:**
- **One usable token per person**, taken from the companion's or scholar's own name (the *ism* wherever it yields a recognisable name).
- **Two words only in five approved cases**, where a single word would make the person unrecognisable: **আবু বকর, আব্দুর রহমান, আবু উবায়দা, আবু হুরায়রা, উম্মে কুলসুম**. These are Principal-approved keepers.
- **Scholars (Tier 5)** contribute their **given name (ism)**; the famous nisba/laqab sits in the উৎস column for the teacher (e.g. *মুহাম্মাদ* → ইমাম বুখারি), never the nisba as the usable name.

**Distinctness rule:**
- **Male lists are strictly distinct across classes** — no male name appears in more than one class pool.
- **Female lists may share names across classes** (Principal decision D1-iii), because the authentic female pool (wives & daughters + sahabiyyat + righteous Muslim women + female transmitters) is smaller; the foundational names (খাদিজা, আয়েশা, ফাতিমা …) deliberately recur. The anti-repetition rule above (within one lesson set) is the operative guard, not cross-class uniqueness.

**Spelling house-style (Principal-confirmed):** উমর / উসমান / আয়েশা / ফাতিমা / যুবায়ের / যায়েদ / মুয়াজ. The "z" (ز) sound is rendered **য** (যুবায়ের, যয়নব, রাযিয়া) following these anchors. The বাংলা column is the authoritative, editable house-style — mark any spelling to standardise and it propagates file-wide.

**Vetting note (C-10 seed names).** REF-01 §4.1 C-10 seeds three example names "where suitable": **শুভ (Shubho) — EXCLUDED** (reads non-Muslim; secular/Hindu Bengali name); **রুবি (Rubi) — EXCLUDED** (a Western gemstone loan-name, contrary to C-10's own aim); **টুলি (Tuli) — EXCLUDED** (cross-community pet-name, no Islamic referent). None enters this pool. The REF-01 in-file example wording is locked and unchanged; this screen is recorded here and routed to the next REF-01 supersede (see CROSS_PROJECT_INDEX / TODO).

**Alignment note (Salafi framing, D-020).** Where a name overlaps a figure venerated through shrine/tomb or tariqah practice (e.g. certain later "Nafisa / Sakina / Rabia" associations), this file lists the name only as a **common, in-use Muslim name** and does **not** attribute it to that figure or present that figure as a model. Authentic sahabiyyat and the Mothers of the Believers are cited by name as honoured (রা).

## §4 What this file does NOT govern

- **Non-name C-10 replacements** (Western foods, clothing, settings, idioms) — those stay with REF-01 §4.1 C-10 directly; this file is the **names** instrument only.

## §5 Append-extensibility protocol (living file, like REF-19)

This file is **append-extensible**: growing a class pool toward the 40-name ceiling, or adding a class when the school expands a grade, is a **data-fill**, not a methodology change, and does **not** trigger a version supersede.

To add names:
1. **Pick the tier and class.** Keep the within-class tier order (T1 → T3 → T4 → T5 for male; T2 → T4 → T5 for female).
2. **Male:** confirm the name is not already used in *any* class pool (strict cross-class distinctness). Search the file first.
3. **Female:** recurrence is allowed; only avoid duplicating the same name *twice within the same class list*.
4. **Vet before adding** against the §0 alignment rules: clearly Muslim-Bengali; single word (or one of the five approved two-word keepers); for scholars use the ism with nisba in the source column; do not attribute a name to a shrine/tariqah-venerated figure.
5. **Record** the addition in §6 with a one-line note (date, class, names added). Methodology/structure edits (not mere name additions) require a version supersede per README §5.3 and a `PROJECT00_DECISIONS.md` row.

If a borderline name arises (suitability unclear), **flag it for the Principal** rather than adding silently — mirroring the C-10 seed-vetting in §0.
