# scd-central

Private monorepo for all SCD (School for Community Development, Sylhet) school workstreams:
curriculum, question papers, support books, class tests, scholarship alignment, accounting.

- **Protocol:** AGENTS.md (CLAUDE.md points there)
- **Workstream index:** REGISTRY.md
- **Shared authority files:** canon/ (cited, never copied)
- **Shared tooling:** tools/
- **First-time setup:** SETUP.md · **File slotting:** SLOTTING_CHECKLIST.md

The SCD Hub app (`scd-hub`) and the commercial storybook venture live in their own repos.
